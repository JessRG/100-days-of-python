## 🛠️ Setup and Installation

### 1. Clone the Repository
```bash
git clone <your-repository-url>
cd 100-days-of-code
```

### 2. Environment Setup
Make sure you have **Python 3.10+** installed on your system. 

```bash
# Verify your python installation
python --version
```

### 3. Running a Specific Day
Navigate to any day's directory and run the main application file:
```bash
cd "Day 9/Blind Auction Project"
python main.py
```
